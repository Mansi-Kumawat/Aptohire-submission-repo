## 2. The version decision

```mermaid
flowchart TD
    A["17 Oct · First prototype / two approaches explored"] --> B["Version A"]
    A --> C["Version B"]
    B --> D["20 Oct · Built and reviewed"]
    D --> E["Gaps identified"]
    E --> F["Decision: switch main focus to Version B"]
    C --> G["25 Oct · Version B ready"]
    G --> H["Backend nearly complete"]
    F --> H
    H --> I["28 Oct · Backend + remaining core work complete"]
    I --> J["Prototype ready for final validation"]
    J --> K["Production-readiness checks and refinements"]
```

**Why switch?** Version A was built by 20 October, but the team felt it had shortcomings. Rather than settle for it, the team moved its focus to Version B. Version B was ready by 25 October, with the backend nearly complete; by 28 October, the backend and remaining core work were complete.
