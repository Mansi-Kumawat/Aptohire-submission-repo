# AptoHire — AI Utilization Report (Source)

This editable Markdown source accompanies the designed PDF and animated interactive HTML report.

## Purpose
Document both (1) AI used during development of AptoHire and (2) AI capabilities intended inside the AptoHire product.

## Executive snapshot
- Estimated AI-assisted execution: approximately 85%, a qualitative team estimate, not an audited measurement.
- Development tools: Gemini, Claude, ChatGPT and Arena AI.
- Human responsibilities: product decisions, review, manual testing and iteration.
- Product AI vision: project/skill evidence review, skill-based blind matching, profile assistance, and future AI-led skill interviews.
- Product features should be described as live only after implementation and validation.

## AI used to build AptoHire
Gemini, Claude and ChatGPT supported planning, idea exploration, market/product analysis and technical learning. Claude supported prompt refinement and technical documentation. Arena AI supported prompt-led coding across root, student, university, organization and admin portals. Human testing and review remained part of the workflow.

Evidence in `AI_Utilization.zip` includes planning traces/logs, portal coding traces, Claude prompts, technical documentation and API contracts. The backend Arena trace is pending.
